# HELL GATE

Arena graybox 3D con Unity 6000.6.2f1 e Universal Render Pipeline (URP 17.6.0).

## Avvio

1. Installare Unity 6000.6.2f1 tramite Unity Hub.
2. Aggiungere questa cartella come progetto e aprirla.
3. Attendere il ripristino dei pacchetti.
4. Aprire `Assets/Scenes/Graybox.unity`.

La scena contiene stanze collegate, coperture, una rampa e una piattaforma rialzata, con materiali distinti e collisioni. Non sono ancora presenti controlli del giocatore o combattimento.

## Verifica della scena

Con la sola scena Graybox aperta, scegliere `HELLGATE > Validate Graybox`. La verifica controlla il percorso centrale, la continuità del pavimento, la rampa, la piattaforma, le pareti, i collider e i riferimenti a script e materiali. Il risultato viene scritto nella Console.

Sono disponibili soltanto i sorgenti; non è incluso un eseguibile.

Versionare gli asset insieme ai relativi file `.meta`. Cache, log e build generate sono esclusi dal repository.
